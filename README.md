# 🌌 IAE Astro Dashboard (v3.0)
> **Integrated Astrological Engine — High-Precision Personal Astrological Dashboard**

ระบบวิเคราะห์ดวงชะตาบูรณาการความละเอียดสูง คำนวณพิกัดดาราศาสตร์จริงด้วยเอนจินดาราศาสตร์สากล (VSOP87 Ephemeris) แสดงผลไทม์ไลน์ 30 วันล่วงหน้า พร้อมคำแนะนำเชิงกลยุทธ์รายวันสไตล์ Apple/Vercel

---

## ✨ Features
- **30-Day Astronomical Timeline Scanner:** คำนวณตำแหน่งดาวจริงทุกวัน (ไม่มีการคาดเดาองศา)
- **Interactive Energy Curve:** กราฟดัชนีพลังงาน สแกนวันทองคำ (Golden Window) และวันที่ควรระวัง
- **4-Pillar Daily Breakdown:** วิเคราะห์ลึก 4 ด้าน (การงาน • การเงิน • อารมณ์ความสัมพันธ์ • ข้อควรระวังสูงสุด)
- **Multi-System Integration:** ผสานดวงจีน Bazi (เสาประจำวัน) และทักษาไทย (สีมงคล ศรี/เดช/กาลกิณี)
- **PWA Ready:** รองรับการติดตั้งเป็นแอปบนมือถือ iOS และ Android (Add to Home Screen)
